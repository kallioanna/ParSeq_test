# ParSeq_test
Тестовое задание на позицию младшего биоинформатика-аналитика
Полный отчет с пайплайном и результатами находится в папке results

## Задание 1

Для таргетных регионов панели:
- проверено соответствие хромосом панели и референсного генома;
- использована сборка GRCh37.p13;
- выполнена аннотация таргетных регионов по RefSeq;
- определены соответствующие гены, транскрипты и экзоны.

## Задание 2

Для оценки возможной неоднозначности картирования:
- из референсного генома извлечены последовательности таргетных регионов;
- выполнено выравнивание таргетных последовательностей с референсным геномом
  с помощью BLASTN;
- отобраны совпадения со 100% идентичностью и полной длиной таргета;
- удалены совпадения региона с самим собой;
- определены координаты таргетных и гомологичных нецелевых регионов;
- проведена аннотация и интерпретация найденных регионов.

## Используемые инструменты

- AWK
- bedtools v2.30.0
- samtools 1.13
- BLASTN 2.12.0+

## Референс

В анализе использована сборка человеческого генома: **GRCh37.p13**
Для аннотации использовались данные RefSeq.
